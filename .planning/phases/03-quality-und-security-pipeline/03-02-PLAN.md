<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository config -> Renovate bot | Repo-owned automation rules govern when and how dependency PRs appear. |
| local executor -> GitHub branch protection API | A privileged API call changes merge policy for the canonical branch. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | T (Tampering) | `renovate.json` | mitigate | Pin the policy in repo with explicit `matchDatasources` and `minimumReleaseAge: 7 days` so update cadence cannot silently drift in GitHub app defaults. |
| T-03-06 | E (Elevation of Privilege) | `main` branch merge path | mitigate | Apply branch protection with required status checks and `enforce_admins: true` so privileged users cannot bypass failing quality/security gates casually. |
| T-03-07 | R (Repudiation) | Branch-protection state | mitigate | Keep the applied protection payload in `.github/branch-protection/main.json` and verify it via `gh api` so the enforced policy is reviewable and reproducible. |
</threat_model>
