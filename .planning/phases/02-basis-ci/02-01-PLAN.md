<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer/CI -> backend build toolchain | Untrusted dependency resolution and local environment differences can change build behavior. |
| test harness -> Spring Boot runtime | Failing or over-scoped bootstrap can hide missing build prerequisites until CI. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | T (Tampering) | Maven dependency/build chain | mitigate | Use Maven Wrapper plus explicit Java 21 in `backend/pom.xml` so local and CI resolve the same build entrypoint. |
| T-02-02 | D (Denial of Service) | Spring Boot test bootstrap | mitigate | Keep the app minimal in Phase 2 (no DB/mail/security startup dependencies) so `contextLoads()` fails only on real build/bootstrap regressions. |
| T-02-03 | I (Information Disclosure) | Backend starter app | accept | No domain endpoints, secrets, or persistence are introduced in this phase; disclosure risk is negligible. |
</threat_model>
