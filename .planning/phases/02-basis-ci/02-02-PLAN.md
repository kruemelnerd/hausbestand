<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub event payload -> CI workflow | Untrusted PR content controls code under test and can influence job execution paths. |
| CI runner -> Playwright artifacts | Test outputs may contain implementation details that are uploaded outside the ephemeral runner. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04 | T (Tampering) | `.github/workflows/ci.yml` | mitigate | Keep the workflow scoped to build/test commands already present in the repo and avoid privileged write permissions or deploy steps in Phase 2. |
| T-02-05 | I (Information Disclosure) | Playwright artifact upload | mitigate | Upload only `frontend/playwright-report` from the E2E run and do not add environment dumps, secrets, or backend logs as artifacts. |
| T-02-06 | D (Denial of Service) | E2E CI runtime | mitigate | Install only Chromium with `npx playwright install --with-deps chromium` and keep the suite to the existing smoke test for predictable CI runtime. |
</threat_model>
